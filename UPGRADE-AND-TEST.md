# Growth Practice v1.0.5 — Upgrade and acceptance checklist

## Protect the existing app

- [ ] In the working installed app, save a PIN-encrypted backup to private storage.
- [ ] Upload all files from v1.0.5 to the **same** GitHub Pages URL/repository. Do not uninstall or clear Safari website data.
- [ ] Reopen and verify the header is **v1.0.5**, unlock with the **same PIN**, and find at least one older entry/learning checkbox.
- [ ] Confirm older event notes and their historical response tags remain visible, even though the new event form is generic.

## Daily use

- [ ] Today has Mindfulness, Skill rehearsal, Events, and Finish; earlier days are accessible and Back to today works.
- [ ] Mark skill rehearsal **Practiced** and pick **On my own**. Add an optional practice note, navigate away, return and verify the note and method persisted.
- [ ] Switch method to **With ChatGPT** and verify; choose **Not planned**, then **Practiced** again if needed. Verify no older record was erased.
- [ ] In Learn, see the three recommended weekly short sessions and the explanation that you may repeat any scenario and use solo practice.
- [ ] Add a **positive** event: describe joy/contentment, body cues, and what followed.
- [ ] Add an **avoidance** event: describe an urge to delay, resulting actions, and any skills used. Verify both events persist separately.
- [ ] Confirm none of these extra detail fields is required. Flag an event for Monday review.
- [ ] Mark the day complete and verify that later editing reopens it.

## Adaptive deep-dive prompt regression checks

- [ ] Learn → Week 1 has **Copy Deep Dive Prompt**. Copy it and paste into a private note to verify it includes the Library retrieval instruction and the Week 1 fallback (STOP / Missing-Links / Fruzzetti).
- [ ] Learn → Week 2 has the button and the copied prompt **does not assign the old proposed ACT topic automatically**; it requests Week 2's Monday Training Brief instead.
- [ ] Learn → Week 5 and Week 8 show the copy button even when resources are not assigned. They request their respective Monday briefs and instruct ChatGPT to ask if none exists.
- [ ] Review → Copy Monday starter includes an explicit "Next Week Training Brief" instruction.
- [ ] Confirm no reading, rehearsal, or week state changes merely from copying a prompt; daily entries and backup remain intact.

## Skills, reporting and security

- [ ] Bottom navigation shows **Today · Learn · Skills · Review**.
- [ ] Skills shows strong emotion, avoidance, thoughts, connection, and something positive. It no longer consists only of STOP/anger content.
- [ ] Review shows both events and their relevant fields. Copy the report and check its text. Download a weekly PDF and check for missing or cut-off fields.
- [ ] Create another encrypted backup after verifying the upgrade.
- [ ] Confirm Settings, PIN unlock, past-week read-only protection, and offline reopening work on the installed phone.

**If something seems missing:** do not clear data or uninstall the app. Preserve the earlier backup and note the precise app version and steps that produced the problem.
